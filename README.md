# Atelier Nocture — Personal Website

A minimalist, tactile personal website crafted around your chosen visual language:
- **Style**: Flat Minimal 2D line and shape artwork
- **Palette**: Warm beige (`#FAF7F2`, `#F4EFE6`), crisp off-white (`#FFFFFF`), soft chalk accent washes (soft terracotta `#D88A6E`, soft sage `#9AA685`, soft ochre `#E0B589`), and deep ink black (`#1C1917`)
- **Texture**: Soft chalk matte fills & subtle linen grain filter
- **Mascot**: The Geometric Owl

## Included Artwork (Embedded SVGs)
1. **Mascot (Square 1:1)**: Centered geometric owl on a plain warm beige background.
2. **Cover Image (Horizontal 16:9)**: Minimalist landscape with rolling hills, chalk sun, and fine ink botanical branch.
3. **Card 1 (Square 1:1)**: *Ideas & Thinking* — Balanced geometric stones with a curving botanical leaf.
4. **Card 2 (Square 1:1)**: *Projects & Craft* — Interlocking architectural arches and clean steps.
5. **Card 3 (Square 1:1)**: *Connect & Dialogue* — Folded origami envelope blooming with an olive twig.

## Files
- `index.html`: Complete semantic structure with responsive layout and embedded vector artwork.
- `styles.css`: Custom CSS properties, tactile linen grain overlay, typography, and responsive grid.
- `script.js`: Archive category filtering, interactive palette swatches, and smooth form feedback.

## How to View
Double-click `index.html` to open it in any web browser, or serve it with any local static server:
```bash
# Python
python -m http.server 8000

# or npx serve
npx serve .
```
